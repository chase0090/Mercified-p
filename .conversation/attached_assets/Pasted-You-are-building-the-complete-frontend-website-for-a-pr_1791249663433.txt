You are building the complete frontend website for a premium Nigerian fashion brand called MERCIFIED ARTISTRY.

THIS IS A FRONTEND-ONLY BUILD.

There must be NO backend.

There must be NO database.

There must be NO authentication.

There must be NO CMS.

There must be NO admin dashboard.

There must be NO Convex.

There must be NO Cloudinary integration.

There must be NO API integration.
