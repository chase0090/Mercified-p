name: Responsive navigation direction
description: The user's explicit navigation preference for Mercified Artistry.

Use a conventional, compact horizontal desktop navigation with Home, About, Collections, Portfolio, Heritage, Process, Contact, and a restrained More dropdown for secondary pages. On smaller screens, use a simple unnumbered navigation drawer. Never show the rejected oversized numbered editorial-index menu.

**Why:** The user explicitly rejected the giant numbered navigation and specified familiar premium-site navigation instead.

**How to apply:** Preserve this structure for future navigation changes; keep work scoped to the header and menu rather than redesigning other site sections.
