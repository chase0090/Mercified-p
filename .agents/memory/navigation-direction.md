---
name: Responsive navigation direction
description: The user's explicit navigation preference for Mercified Artistry.
---

Use a clean, horizontal desktop navigation with 4 core destinations: Home, About, Portfolio, Contact. 
Runway is curated directly under Portfolio (as Runway Editions with spotlight and filtering). Collections, Heritage, Process, Sustainability, and Journal are not on the top menu because Heritage, Process, and Sustainability are embedded directly into each garment in the Portfolio. On mobile, use a clean, unnumbered slide-in navigation drawer.

**Why:** The user requested an un-cluttered menu where Runway is integrated under Portfolio, redundant pages are eliminated, and both light and dark mode text contrast is crystal clear.

**How to apply:** Ensure desktop viewports show the 4-item horizontal row with sticky blurred background, crisp contrast in both light and dark themes (never dark text on dark background when scrolled), and mobile viewports provide the unnumbered drawer.
